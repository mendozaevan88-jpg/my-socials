# Evan's portfolio

A one-page personal site with a liquid glass look: floating, draggable windows over a blurred photo background. It links to my socials and my guitar cover.

No build step, no dependencies. It is plain HTML, CSS and JavaScript.

## Run it

Open `index.html` in a browser. The fonts (Bricolage Grotesque and Figtree) load from Google Fonts, so you need an internet connection.

## Put it online

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/`.

## Make it yours

- **Links:** edit the `href` addresses in the `find-me-online` window.
- **Text:** edit the `hello.txt` window.
- **Glass style:** edit the `.glass` rule in the CSS.
- **Photos:** replace `photo1.jpg`, `photo2.jpg` and `photo3.jpg`, keeping the same names.
